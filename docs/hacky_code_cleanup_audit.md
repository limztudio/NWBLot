## Changes

| Domain | Problem and resulting behavior |
| --- | --- |
| Logger lifecycle | Remove the base worker's successful no-op initialization/update/destruction defaults and the standalone client's empty global initialization. Optional global initialization is selected only when the concrete worker supplies it; the existing CURL initialization and actual queued/interval worker shutdown remain. |
| Logger frame | Delete the empty shared `frame.cpp` lifecycle methods and their registration. Windows uses blocking `GetMessage`, handles its failure result, and destroys the native window through `WM_CLOSE`/`WM_DESTROY`. Font cleanup checks `DeleteObject` and emits an explicit diagnostic on failure; native handles are cleared before frame storage is reset. Linux retains its signal-driven exit and explicit sleep cadence. `showFrame` is a void command in both platform implementations, and main no longer contains its unreachable failure branch. |
| Logger startup | Enqueue the listening message only after successful frame initialization. Previously the worker could consume that message before the frame's message store and native list existed, leaving the window blank even though the file contained the startup line. |
| Logger output | Act on `ProcessedMessageFile::writeLine` failure. The standalone client emits an error to stderr; the server reports the failure through its frame and, on Windows, stderr. Linux receives one console diagnostic through the frame. No failure message is recursively enqueued into the same log file. |
| Texture publication | Replace delete-before-replacement with exclusive creation of both `.tmp` files, checked writes/flush/close, preservation of existing destinations as `.old`, and rollback of the converter's owned changes. Occupied work paths are rejected, including dangling links on Linux. Old outputs are restored on ordinary publication failure; failed restoration retains the backup and reports its location. A non-throwing scope guard also owns cleanup during exception unwind. |
| Launcher | Remove the argument adapter that only copied a sequence before another copy. Requested POSIX process stopping now fails explicitly when `pkill` is missing, returns an unexpected status, or reports a diagnostic. Status 1 without diagnostics remains the valid no-match result; application launch does not proceed after a stop failure. Diagnostic text is limited to 2,048 bytes. The lifecycle guard now covers validation, stopping, and launch setup, so failure before application creation closes an owned profile logserver even when detach was requested. |
| Blocking I/O | Expose the existing POSIX read/write transfer wrappers on Apple and Unix as well as Linux and Android. The converter's `fcntl.h` guard now matches its non-Windows staging path. This is source portability support, not a claim of native execution on every platform. |
| FBX CLI diagnostics | Route semantic argument rejection through the existing `CLI::App::exit(CLI::ValidationError, stdout, stderr)` contract instead of compile-filtered logger warnings/errors. Invalid values and retired aliases report their explanation on stderr in every configuration and fail before replacing the destination. The model-package integration checks six malformed argument cases plus retired-alias rejection and canonical recovery. |
| Graphics contract | Remove unused no-op live-object reporting and latewarp APIs. Remove raster controls that the current selected lowering never consumed, including programmable sample-position storage; migrate the two ineffective scissor-enable calls. Actual viewport/scissor recording and framebuffer-driven multisampling remain. |
| Shader visibility | Lower each ray stage independently, including intersection and callable, instead of broadening any ray-stage request to four stages and omitting two. Reject unknown visibility bits before creating a bindless layout. Existing valid masks, the explicit omission default, feature admission, and native error handling remain. |
| Scene BVH | Require the current instance primitive-cost array through `NotNull<const u32*>` rather than retaining an optional input and uniform-cost fallback. The only owning caller supplies every cost from the prepared instance's primitive count after the zero-instance return. Recursive calls reuse the required input without repeated validation. SAH calculations, partitioning, and degenerate safeguards are unchanged. |
| Caustic shader | Remove the dormant fixed-grey debug macro and return branch. Real sampled irradiance, out-of-range black, and the explicit disabled-sampling black result remain. |
| Generated shaders | Remove the unconditional optimization-disable override for generated AVBOIT accumulation pixel shaders and its extra append parameter. These entries now use the same current `Default` optimization contract as the other generated stages. The old comment cited a historical compiler assertion; the fresh optimized asset cook, recorded optimized visual workflows, three sustained M4 repeats, and hardware-boundary workflows have passed with the configured current compiler. These are current-workload qualification results, without an isolated shader-performance attribution. |
| Benchmark render admission | Remove the unused `NWB_RENDER_UNFOCUSED` setup from M4 and three other A/B harnesses. The publication guarantee assumes a single writer for the output pair and covers ordinary operation failure or exception unwind when the filesystem permits restoration. It does not provide concurrent-writer coordination or a crash-atomic two-file filesystem transaction. Unrelated pre-existing `.tmp`/`.old` files are not converter-owned cleanup targets.
