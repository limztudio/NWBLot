notes: GNU libmicrohttpd HTTP server for the log server. Official 1.0.10 snapshot; vendored src/include + src/microhttpd only, with generated autotools Makefile.in files excluded. NWB CMake remains local/offline integration and compiles its explicit plain-HTTP source set. The vendored Windows and Linux/POSIX builds generate MHD_config.h into the CMake binary tree from the NWB integration template; the Linux build is static and links pthread. Consumers include their own POSIX socket declarations; the loopback integration test reads its ephemeral port from the actual listen socket when using MHD_OPTION_SOCK_ADDR_LEN. Removed the unused imported-library helper include after canonical dependency discovery replaced raw-target synthesis. NWB-local patch (validation cleanup 2026-10-19): removed 5 redundant checks proven unreachable in microhttpd/connection_https.c and microhttpd/mhd_opt_matrix.c (see .git/validation-audit-20261019 register); re-apply or drop on re-vendor. NWB-local return handling: check connection lookup/idle state, fd-set admission, socket lifecycle, ITC clearing, multipart progress, daemon run status and test setup; preserve void init callbacks without return casts.
