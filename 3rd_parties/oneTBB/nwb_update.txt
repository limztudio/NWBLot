notes: Intel oneTBB task scheduler / scalable allocator. Vendored include/ and src/{tbb,tbbmalloc,tbbbind,tbbmalloc_proxy} only; NWB CMake normalizes custom dbg/opt/fin configurations for imported Linux TBB auxiliary targets as well as tbb and tbbmalloc. Linux still links the system TBB runtime, but consumers include this vendored header tree so NWB-local patches apply. The Windows nwb_vendor_tbb source list retains numa_allocation.cpp so its exported interleaved NUMA allocation symbols resolve at link time. Windows RTM/wait-package flags and ITT notification are enabled only for x64 because upstream does not support those paths on ARM64. NWB correctness patch in detail/_segment_table.h always releases destination segments through the original allocator before POCMA, because internal_move() clear()s only after the allocator has already been replaced.
