notes: Top-level CMake wrapper builds the in-process .rgd GPU-crash decoder backend (rgd_backend / nwb_rgd_decode); summary decode only. Consumes flattened dev_driver via nwb::dev_driver_headers. The NWB-authored nwb_rgd_decode shim suppresses backend console output under a mutex while parsing. NWB adapts SystemInfoReader::Parse to pass static_cast<rdfChunkFile*>(chunk_file), matching system_info_utils v2.3's enabled RDF C-API overload. The disassembler/DXBC/code-object .cpp+.h are EXCLUDED from the build but KEPT on disk as a deferred ISA-disasm feature. Pruned dead non-build files and upstream pix_events_decoder CMake; kept License.txt + RGD_NOTICES.txt. NWB-owned decode boundary uses the engine Expected contract with static error text, explicit RDF C API open/format admission, and no local catch-and-continue handlers. It checks serializer failures while preserving partial report sections. The shim source alone uses the engine C++23-or-newer language flag; upstream backend sources remain unchanged.
