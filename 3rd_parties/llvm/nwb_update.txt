Built STATIC via rewritten CMakeLists.txt; Nested BLAKE3 C implementation is lifted out to 3rd_parties/blake3 from its official upstream. The prefixed llvm-c/blake3.h entry points are wired to nwb::blake3 and keep the existing C ABI. Unity build enabled with SKIP_UNITY_BUILD_INCLUSION on 37 colliding vendored sources (plus ConstantFolding.cpp skipped via per-source compile options). NWB-local maintenance trims stale and redundant source comments. The adapted XXH3 implementation is replaced by wrappers over nwb::xxhash. Keep the LLVM signatures and map the 128-bit return fields explicitly. The XXH3 wrapper compiles separately because the LLVM and official headers both declare a type named XXH128_hash_t.
