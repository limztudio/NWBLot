notes: gtest only (no gmock). Vendored the googletest sublib (include/ + src/ + LICENSE). Built from the gtest-all.cc unity source via an NWB-authored CMakeLists with public headers marked SYSTEM; the engine supplies its own test entry point (tests/common/gtest_nwb_main.cpp) instead of gtest_main, which forces threadsafe death tests after threaded engine initialization. The std::any printer is disabled with GTEST_HAS_RTTI because the Microsoft standard library omits std::any in the engine's no-RTTI configuration. Samples/docs/tests not vendored.
