The native loader uses production ShaderCook, identical production includes and entry main. It validates active metadata, compiles each reference using its original default variant without defines, and separately compiles the candidate with its explicit stage selector. Do not replace references with candidates to satisfy parity. Include identities and cooker must be frozen together with source identities when comparing modules.

The paired comparisons require exact RGBA16 output identity. Additional preparation checks independently verify fixed-point flux and regular-grid receiver area. Upsample checks require constant-color/activity behavior, preserve the original zero at an even extent's final pixel where all displaced taps underflow, and check invalid receivers, zero input, odd/tiny extents, partial workgroups and untouched output guards. These fixture declarations do not claim test execution.
